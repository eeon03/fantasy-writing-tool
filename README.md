# Fantasy World Engine

A modular creative writing world-building, outlining, brainstorming, plotting tool for personal use.
Built in Python.

## Modules
- M1 — World notebook: characters, locations, lore, magic systems
- M2 — AI brainstorm tool with safeguards (in progress)
- M3 — Originality tools: trope detection, influence tracking
- M4 — Plot engine: consequence mapping, pacing analysis
- M5 — Visualisations: relationship web, world timeline, pacing visualizer
- M6 — Web interface and outline export

## Built with
Python, JSON storage, Anthropic API
